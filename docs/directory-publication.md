# 公開資料發布

## 同仁操作

- 新增／修改／下架／還原／排序：照常儲存，Worker收到Google確認成功後自動同步公開清單。
- 狀態「已發布」表示資料已存入Cloudflare，重新開啟前台可讀取。
- 狀態「已儲存，尚未發布」表示Google編輯成果仍在，但前台維持上一份成功發布的清單。按「同步發布」重試，不必重新儲存或重建卡片。
- 直接修改Google試算表：修改完成後進後台按「同步發布」。未儲存的後台表單內容不會因此發布。
- 不會自動刷新已經開著的前台分頁；重新整理可讀取新版本。

## 設計與限制

- `directory_publication`為REPORTS_DB內獨立表，不修改回報資料或原始試算表。部署時先執行0002資料表建立，再部署Worker。
- getDirectory直接讀D1單筆公開清單，回傳no-store，避免瀏覽器延長已下架內容顯示。只有第一次尚無清單時，從Google公開端點建立初始資料。
- 公開清單僅接受固定GAS_URL的getDirectory回應，資源須visible=true且未刪除；欄位採白名單，不接受用戶端上傳清單，也不發布directoryList後台資料。
- 手動發布先透過GAS directoryList驗證當前帳號，僅admin/editor/reviewer可執行。既有登入、停權規則不變。
- 發布前後核對Google cache_version；來源變動、逾時或資料庫失敗均回傳pending。SQL條件更新確保低版本及同版本較早開始的請求不能覆蓋新版。
- 保留上一份發布成果，直到新版成功寫入；因此同步失敗時需要管理同仁按同步發布處理，特別是涉及下架的修改。
- 直接改試算表不會自動更新Cloudflare；必須手動同步。不宣稱有排程監控或背景重試。
- Google公開端點本身沒有跨多張表的交易快照；版本前後核對可偵測一般後台並行修改，直接改表時應完成整批編輯後再同步。
- 本次僅加速教師手冊前台；LINE既有搜尋索引的更新機制不在此變更範圍。

## 驗證紀錄

- 14項自動檢查通過：公開欄位篩選、無Google請求的快照GET、SQLite實際版本條件、來源變動／斷線保留原快照、表單封裝儲存自動發布、拒絕操作不能發布、手動發布角色限制、同步失敗仍保留儲存成功，以及既有快取／LINE回覆檢查。
- Worker版本：1eda9f27-83b7-498f-b850-548d676793aa。
- 初始快照56筆，無hidden資源、user或trash後台欄位。
- 三次正式API量測0.79、0.63、0.64秒，來源均為snapshot；是樣本，不代表所有網路環境的速度保證。
- Context7工具不可用，改查Cloudflare官方文件：https://developers.cloudflare.com/d1/worker-api/prepared-statements/

## 回復舊讀取方式

若需要回復，將Worker及前台／後台程式恢復至5194bee並重新部署，恢復從Google讀取；保留D1公開資料表即可，無需刪除原始資料或新表。
